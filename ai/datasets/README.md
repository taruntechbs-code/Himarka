# Agricultural Produce Datasets — North Eastern India

## Target Produce Classes
1. **King Chilli / Bhut Jolokia** (*Capsicum chinense*)
2. **Northeast Organic Ginger** (*Zingiber officinale*)
3. **Local Plum & Cherry Tomatoes** (*Solanum lycopersicum*)
4. **Winter Cabbage & Cauliflower** (*Brassica oleracea*)

## Dataset Organization
- `raw/`: Unprocessed high-resolution images from field storage units and annotations.
- `processed/`: Normalized 640x640 YOLO-formatted images with train/val/test splits.
